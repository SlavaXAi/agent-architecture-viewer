# Визуальная архитектура агентов

Навык для Codex: создаёт в вашем проекте понятный интерактивный просмотр архитектуры ИИ-агентов в стиле n8n.

Нажимаете на блок — видите его роль, внутренние шаги, входные данные и возвращаемый JSON. По умолчанию схема выстраивается слева направо: вход, агент и результат; ресурсы симметрично сверху, инструменты ровным рядом снизу. Масштаб плавный, с низкой чувствительностью для трекпада Mac. По запросу доступно ручное изменение изгибов и концов стрелок с привязкой к портам, отменой и повтором.

**Схема ИИ** — исходный вариант, который Codex обновляет вместе с кодом агента. **Мой вариант** — ваше расположение и визуальные правки. Переключение на исходный вариант не стирает личный; он сохраняется в браузере. Ручные стрелки не меняют исполнение агента.

## Как использовать

Передайте Codex ссылку и напишите:

> Установи навык agent-architecture-viewer из https://github.com/SlavaXAi/agent-architecture-viewer — папка agent-architecture-viewer. Добавь в мой проект раздел «Агенты» с кликабельной архитектурой, внутренними шагами и входными/выходными JSON. Используй переносимую ровную раскладку навыка и плавный зум для Mac. Нужен просмотр исходной схемы; личный вариант с ручными стрелками добавляй только по моему запросу. Сначала кратко объясни объём изменений.

Можно скачать репозиторий через **Code → Download ZIP** и передать папку `agent-architecture-viewer` своему Codex. Если у вас уже создан визуализатор по прежней версии навыка, попросите Codex применить обновлённый навык к нему.

## Что внутри

- [SKILL.md](agent-architecture-viewer/SKILL.md) — инструкции навыка.
- [Контракт описания](agent-architecture-viewer/references/architecture-contract.md) — структура блоков, связей, примеров и личного вида.
- [Вымышленный пример](agent-architecture-viewer/assets/example-architecture.json) — стартовое описание агента.
- [Адаптер холста](agent-architecture-viewer/assets/interactive-canvas.js) — пример интеграции AntV X6: карточки HTML, масштаб, перемещение, ручки стрелок, привязка, история и выравнивание.
- [Ровная раскладка](agent-architecture-viewer/assets/architecture-layout.js) — общий шаблон одного специалиста, зеркальные дорожки без пересечений и сохранение реальных связей.
- [Жесты трекпада](agent-architecture-viewer/assets/canvas-gestures.js) — плавный зум вокруг курсора, Chromium и WebKit.
- [Проверка сохранённого вида](agent-architecture-viewer/assets/canvas-state.js) — геометрия и связи без содержимого документов.
- Упаковщик — делает архив только из файлов самого навыка.

Адаптер проверен с `@antv/x6` 3.1.8 и `tslib` 2.8.1. Его подключают через сборщик вашего проекта; карточки и сохранение задаются колбэками. Пример подключения есть в контракте. Стандартный шаблон рассчитан на одного агента и до восьми инструментов; для более сложной топологии задаётся собственная сгруппированная раскладка, без удаления связей. [X6](https://github.com/antvis/X6) — открытый движок с лицензией MIT. Уведомления о лицензиях зависимостей нужно сохранять при сборке.

Навык подстраивается под существующий интерфейс и стек. Это инструкции и переносимый пример холста, а не отдельное готовое приложение или запускаемый агент.

Просмотр не запускает модели и поиск. Учебные примеры, сохранённые наблюдения и работающие модули подписываются отдельно. В пакете нет API-ключей, рабочих документов или данных конкретного проекта.

В обычном ChatGPT можно использовать текст навыка для проектирования. Для изменения приложения нужен доступ к его файлам и подходящие инструменты.
