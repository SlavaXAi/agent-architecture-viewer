# Визуальная архитектура агентов

Навык для Codex: создаёт в вашем проекте понятный просмотр архитектуры ИИ-агентов в стиле n8n.

Нажимаете на блок — видите, что он делает, какие инструменты вызывает, что получает на вход и какой JSON возвращает. Схема обновляется вместе с изменениями агента.

## Как использовать

Передайте Codex ссылку на этот репозиторий и напишите:

> Установи навык agent-architecture-viewer из https://github.com/SlavaXAi/agent-architecture-viewer — папка agent-architecture-viewer. Затем добавь в мой проект раздел «Агенты» с кликабельной архитектурой, внутренними шагами инструментов и входными/выходными JSON. Нужен только просмотр, без редактора связей. Сначала кратко объясни объём изменений.

Можно скачать репозиторий через **Code → Download ZIP** и передать папку `agent-architecture-viewer` своему Codex.

## Что внутри

- [SKILL.md](agent-architecture-viewer/SKILL.md) — инструкции навыка.
- [Контракт описания](agent-architecture-viewer/references/architecture-contract.md) — структура блоков, связей и примеров.
- [Вымышленный пример](agent-architecture-viewer/assets/example-architecture.json) — стартовое описание агента.
- Упаковщик — делает архив только из файлов самого навыка.

Навык подстраивается под существующий интерфейс и стек вашего проекта. Это инструкции для создания визуализатора, а не готовый запускаемый агент или универсальный компонент приложения.

Просмотр не запускает модели и поиск. Учебные примеры, сохранённые наблюдения и работающие модули должны быть подписаны отдельно. В пакете нет API-ключей, рабочих документов или данных конкретного проекта.

В обычном ChatGPT можно использовать текст навыка как инструкцию для проектирования. Для изменения приложения нужен доступ к его файлам и подходящие инструменты.
